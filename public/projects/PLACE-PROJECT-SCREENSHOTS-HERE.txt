PROJECT SCREENSHOTS (optional)
==============================

Drop real project screenshots here if/when you have them, e.g.:
       public/projects/breast-cancer-app.webp
       public/projects/fire-weather-index.webp

By default, each project shows a clearly-labelled "Conceptual preview" built
from CSS (never a fake screenshot). To swap in a real image, edit
components/ui/ProjectVisual.tsx and render a <next/image> for that project
slug pointing at your file in this folder.

You can delete this .txt file at any time.
